# 전자회로 마스터

특성화고 전자과 기초 과목 **「전자 회로」**(2015 개정 교육과정) 학습 도구입니다.
**배우기 → 게임 → 연습 → 종합시험 → 오답노트** 순서로 한 장에서 끝납니다.

🔗 https://hongyul67-cpu.github.io/electronic-circuit-master/

> **암호가 걸려 있습니다.** 교과서 본문과 출제용 평가 문항을 근거로 만든 도구라
> 파일 자체를 AES-GCM 으로 암호화해 배포합니다. 코드는 선생님께 받으세요.
> 짝이 되는 도구 — [디지털논리회로 마스터](https://hongyul67-cpu.github.io/digital-logic-master/)

## 📽️ 전자칠판 수업자료

교실 앞 화면에서 교사가 끌고 가는 **수업용 슬라이드**입니다. `📽️ 수업자료` 탭에 있습니다.

| 단원 | Ⅰ | Ⅱ | Ⅲ | Ⅳ | Ⅴ | Ⅵ | Ⅶ | 합계 |
|---|---|---|---|---|---|---|---|---|
| 슬라이드 | 14 | 8 | 11 | 11 | 8 | 8 | 5 | **65** |

- **빈칸 364개** — 요점의 빈칸을 누르면 답이 드러납니다. 학생에게 먼저 물어보고 누르세요
- **발문 27개 · 퀴즈 40개** — [발문 열기] → [퀴즈 열기] → [정답 열기] 순으로 한 번에 한 단계만 열립니다
- **그림 20장** — `sym()`(소자 기호 17종)·`wave()`(파형 10종)를 **게임과 같은 SVG** 로 그때그때 그립니다.
  교과서 그림을 쓰지 않았고, 대형 화면에서 확대해도 깨지지 않습니다
- 넘기기는 `←` `→` 키(프레젠터 리모컨) 또는 화면 아래 [◀ 이전] [다음 ▶]
- 화면은 모든 도구가 함께 쓰는 `board.js`, 원고는 `content.js` 의 `LESSON` 이 맡습니다

## 자료의 출처

- 교과서 **『전자 회로』**(2015 개정 교육과정 · 전기전자 전문 교과) Ⅰ~Ⅶ단원 본문 258쪽
- **「고등학교 전자회로 2015개정 교육과정」**, **「성취기준·평가기준」**, **「연간지도계획」**
  → 단원 구성과 소단원 순서는 이 세 문서를 그대로 따랐습니다. 임의로 짜지 않았습니다.
- 수업자료(전자칠판) — 위 세 문서의 단원 구성 + **강의용 PPT 19개(슬라이드 572장)** 의 진행 순서를 대조했습니다
- 문항 — **「Ⅰ~Ⅶ단원 내신대비 대단원평가(출제용)」** 7개 파일의 선택형·단답형
  + 교과서 각 중단원 마무리 「개념 확인하기」

원자료(교과서 PDF·출제용 hwp)는 **이 저장소에 올리지 않습니다**(`.gitignore`).

### 원본 정오표

출제용 파일의 **정답 번호가 풀이와 어긋난 곳**이 세 군데 있었습니다.
번호가 아니라 **풀이 본문을 근거로** 바로잡아 실었고, 해당 문항 해설에 그 사실을 적어 두었습니다.

| 위치 | 원본 | 바로잡음 |
|---|---|---|
| Ⅰ단원 선택형 5 | 정답 ⑤ | 풀이가 "억셉터"라고 밝힘 → **억셉터** |
| Ⅰ단원 선택형 8 | 정답 ③(소량 생산) | 풀이가 "대량 생산"이라 발문을 **"장점이 아닌 것"** 으로 정정 |
| Ⅴ단원 선택형 10 | 정답 ④ | 풀이가 "PCM"이라고 밝힘 → **PCM** |

그림·회로도가 있어야만 풀 수 있는 원본 문항은 **옮기지 않았습니다.**

## 고치는 법

```bash
# 1. 평문 원본을 고친다 (커밋되지 않는 파일)
#    content.js  ← LEARN(배우기) · QUESTIONS(문항) · LESSON(전자칠판 원고)

# 2. 다시 구워야 반영된다
python build_lock.py

# 3. 배포
powershell -ExecutionPolicy Bypass -File ..\_dev\scripts\deploy.ps1 -Path "전자회로 마스터" -Message "문항 보강"
```

`content.js` 는 `.gitignore` 라 **이 PC에만 있습니다.** 배포되는 것은 `bank.enc` 뿐입니다.
